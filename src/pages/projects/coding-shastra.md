Coding Shastra is an educational coding platform designed to help developers learn through structured lessons and interactive practice.

It focuses on progressive difficulty, clear learning paths, and practical exercises that reinforce core programming fundamentals.

The backend is a REST API built with Express and Prisma on PostgreSQL, with JWT auth and bcrypt password hashing. Problems are solved in an interactive Monaco-based code editor with syntax highlighting and real-time compilation.
